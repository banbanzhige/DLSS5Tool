# 深度参考状态 · 2026-09-10

现阶段该版本/已测宿主、运行库和输入中，Depth Anything V2 可以生成相对深度图，
但深度输入没有改变 DLSS 增强输出。见 [既有实验](../guidance/GUIDANCE_EXPERIMENT.md)。

产品决定：v2.1.2 暂时隐藏深度推理、参数、分析图入口；发行包去掉深度权重，保留光流。
内部推理、上传和协议保留。不开启额外推理以制造“已使用深度”的观感。

维护者设置 `DLSS5TOOL_ENABLE_DEPTH=1` 后重启可复开；需自行提供合法来源的兼容权重。
仅新增运行库/宿主证明深度能改变输出并有益后再考虑恢复用户入口。
