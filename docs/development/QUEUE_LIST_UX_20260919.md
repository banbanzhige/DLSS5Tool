# 队列列表交互优化（2026-09-19）

## 用户操作

- 三列始终保留：状态、文件、进度。窗口变化时文件列吸收剩余宽度；拖动分隔线有上下限，
  不会把其他列挤出列表。按当前字体计算最小宽度，兼容中英文和主题变化。
- 长文件名以省略号截断并优先保留扩展名；数据中的路径不截断。悬停约 0.5 秒显示完整源路径、
  输出路径和进度。表头右键可恢复默认列宽。列宽调整仅在本次运行期间保留。
- 单击单选；Ctrl 单击增选/取消；Shift 单击连续选择。按住左键跨行拖动连续选中，
  从底部空白处向上拖动也可选择。靠近列表上下边缘自动滚动，松开或离开焦点后停止。
  此次不引入拖动排序；仍使用已有上下移动按钮。
- 右键已选中的行保留整个选区，右键其他行先选中该行。单选支持加载预览、应用参数、重试、
  复制源路径、打开源目录、从队列移除。多选禁用加载预览/打开目录，支持批量参数、重试、复制和移除。
  混合任务中重试只处理失败、已取消或中断任务；参数操作在含已完成任务时禁用，和按钮保持一致。
- 空白处右键提供添加文件/文件夹/图片序列、全选、撤销移除、恢复列宽。
- 底部显示选中数量/任务总数。移除后显示「未删除文件」及撤销按钮。

| 快捷键（列表获得焦点时） | 操作 |
| --- | --- |
| Delete | 从队列移除选中项，不删除源文件或输出文件 |
| Ctrl+A | 全选 |
| Ctrl+C | 复制源路径，多项每行一条 |
| Ctrl+Z | 撤销最近一次移除（本次运行内、一级撤销） |
| Esc | 关闭原生右键菜单；列表中则取消选择/拖动 |
| Enter | 单选时加载预览 |
| ↑/↓、Home/End | 移动选择；配合 Shift 扩选，Ctrl 仅移动焦点 |
| Shift+F10 | 打开当前选区右键菜单 |

快捷键不绑定到全局，不影响输出目录等输入框。导出/队列运行/诊断/切换后端期间禁用队列修改，
右键命令执行时还会重新检查状态。复制路径和浏览选择仍可用。

撤销保存被移除任务及原顺序，不回滚其他任务的状态；已重新添加的同源任务不会被重复恢复。
清空整个队列仍需确认。移除、清空已完成和清空队列均只改队列记录，均可撤销最近一次。
撤销记录不跨应用重启保存。

## 实现

- 新增 `dlss5tool/queue_list.py`，集中处理列宽、显示截断、鼠标/键盘、右键及悬停提示。
- 原 `gui.py` 队列后端继续负责持久化、导出和设置快照；新增统一可编辑状态检查及一级移除撤销。
- 没有修改解码、超分、补帧、模型或编码流程；没有打包/上传。
- 按 UI/UX 技能要求，拖动保留键盘/按钮替代，错误风险操作说明作用范围，浅/深主题沿用现有颜色。
