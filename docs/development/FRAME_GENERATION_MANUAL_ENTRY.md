## 实际执行链路

恒定帧率视频及时间戳检查 → 可选 RTX Video 超分 → 可选 DLSSNR 增强及强度混合
→ 最终帧 NVOFA 反向光流 → DLSSG → NVENC 编码 → 现有音轨封装。

真实帧只超分/增强一次，生成帧不回灌。空间/时间倍率独立。
SDR 使用 RGBA8，PQ/HLG 使用归一化 RGBA16F 和 10-bit 输出，分析副本不替代 HDR 输出。
NVOFA 以完整目标尺寸（仅边缘对齐填充）计算，不自动换成 RAFT 或降低分辨率。
输出分辨率、倍率、位深或 NVENC 不支持时明确报错，不自动降级。

实验采用平面深度及静止正交相机假设，不宣称为真实游戏深度或通用视频适配的最终方案。
2×调用官方 DLL；3×/4×只对固定哈希 310.7 与 RTX 4070 SUPER 启用已记录的进程内兼容适配，
不改磁盘 DLL/系统驱动设置，且已知存在部分中间时刻偏差。下拉框悬停提示和导出日志保留说明。

## 范围与限制

- 支持 MP4/MKV/MOV 导出、进度、取消、不覆盖源片/已有结果、原音轨按既有策略封装。
- 当前要求 CFR 且视频 PTS 从零开始；VFR、时间戳跳变和明显非零起点会拒绝，
  不是通过平均 fps 把它们悄悄转换。不是完整音视频复杂编辑时间线实现。
- 最终宽高须为偶数且在 128～8192 内，还受实际 GPU/编码器能力约束；不会自行缩放到支持尺寸。
- 3×/4×尚未消除既有时间位置偏差；遮挡、字幕、运动模糊、HDR 画质需人工查看。
- 切镜检测是保守实验阈值，不能保证识别所有切镜；识别后重置模型，按切镜保持处理。
- 首帧初始化没有生成画面；末尾/切镜保持分别计数，不计为生成帧。
  正常连续帧对返回无效状态会停止，不用重复帧冒充成功。
- 已接入主播放器、单项和批量队列的共享处理路径；性能不足时缓冲，不保证实时播放。插帧任务按顺序处理，
  不使用分段并行；对比两侧分别插帧后合成，分界线不参与运动分析。
- 耗时操作在后台线程，原生 DLSSG 在隔离进程，管道操作有超时；取消需等待当前其他组件操作返回。
  主界面沿用已有导出中关闭保护及取消按钮。
- 未打包发布；日志在 `var/fg-experiments/<任务ID>/`，包括 native.log/result.json。
  公开日志前检查本地路径及文件名。
