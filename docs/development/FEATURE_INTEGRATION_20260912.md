## 光流worker接入方式

`run.bat`在未显式指定`DLSS5TOOL_GUIDANCE_PYTHON`且已存在仓库CUDA环境时，将它设为
`tmp/guidance-cuda-env/Scripts/python.exe`。
开发版`GuidanceSession`用该解释器运行`-B -m dlss5tool.guidance_worker`，工作目录为仓库根。
继续读取现有mods中的模型/模块配置，不下载安装、不复制Torch/CUDA、不覆盖冻结worker。

冻结EXE忽略此开发环境覆盖，仍使用自己的增强组件。直接绕过run.bat运行`python gui.py`时，
除非自行设置上述环境变量，否则仍使用mods中的原冻结worker，不能获得全部新版传输优化。
清理tmp时仍须保留被run.bat引用的guidance-cuda-env。
