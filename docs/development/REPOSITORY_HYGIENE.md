# 仓库卫生守则

适用于开发者和自动化代理。目标是让临时空间有预算、有归属、可回收；不裁剪必要运行依赖，
不以清理为由删除用户数据、唯一模型或回滚保障。

## 目录与生命周期

| 内容 | 位置 | 默认保留规则 |
| --- | --- | --- |
| 构建中间文件 | `build/` 或任务内 `build/` | 验证完成后删除；失败排查最多保留 7 天 |
| 解压验证包、冻结候选、一次性实验 | `tmp/<任务>-<YYYYMMDD>/` | 成功交付后清理；未结束任务默认 7 天后复核 |
| 实验输出 | `output/<任务>/` | 保存小型报告、参数、哈希；大视频/逐帧输出验证后清理，默认 7 天后复核 |
| 当前开发环境 | `.venv/`；已有专项环境保留原路径 | 长期复用，升级前记录版本；不按日期自动删除 |
| 已安装组件、模型、SDK | `mods/`、`runtime/`、`third_party/`、`amd_backend/` | 持久资产，不参加普通临时清理 |
| 正式发行包 | `dist/` 或明确批准的外部发行目录 | 本地默认保留当前与上一已验证版本；更旧版本核实归档后逐项批准清理 |
| 回滚备份 | 明确记录的备份目录 | 默认一个已验证回滚版本；替换、过期或删除都须确认 |
| 设置、队列、原始素材 | `var/` 及用户指定目录 | 用户数据，不自动清理 |

保留期限是**复核期限，不是自动删除授权**。失败任务保留最小复现材料即可，不必保留整套环境副本。
历史目录不强制立即迁移；先审计引用，再单独修改路径并验证。

## 容量预算

- 每次下载、复制、打包或解压前，记录目标盘可用空间和临时目录体积。
- 峰值预算必须包含同时存在的组件副本、ZIP、分卷、解压验证目录与构建缓存；
  要求可用空间至少为“预计新增峰值 + 15 GiB 安全余量”。不能只按最终压缩包大小估算。
- `tmp/` 总量超过 **20 GiB** 时列出最大的目录；达到 **30 GiB** 时暂停新增大型产物，
  先清理已获准的内容或请求调整预算。现存持久依赖也计入总量，不能忽略它们来绕过限额。
- 目标盘不足 **15 GiB** 时暂停大型生成/复制/下载。单任务预计新增超过 **5 GiB**，
  必须先说明峰值和回收方案；超过上述预算或写往新外部目录须取得用户同意。
- 同一任务最多保留一个完整候选和一个明确回滚版本；中间迭代复用依赖，
  不再按每次试验名称累积整套 Torch/CUDA。不得用可写目录联接/硬链接冒充隔离副本。
- 正式打包仍遵守 [打包约定](../release/PACKAGING_INDEX.md)，卫生规则不授权依赖裁剪或降画质。

这些是执行约定，不是已经部署的磁盘配额或自动清理服务。

## 任务登记与收尾

新建任务目录时，在其中保存小型 `TASK.md`，记录：任务/负责人、创建时间、到期日、
输入来源、重建命令与依赖版本、预计峰值、产物位置、保留或删除条件。
因测试失败而保留时，补充失败原因和下一次复核日期。不得在记录中保存凭证或私人媒体内容。

交付前必须：

1. 将可复用代码整理到 `scripts/`，将结论和必要参数整理到 `docs/`；保留有价值的小型报告。
2. 对需要保留的最终包确认校验值与验证结果；归档不是仅写一个可能不存在的路径。
3. 清理本任务明确创建且不再使用的可重建中间文件；旧文件、用户文件或归属不明内容先询问。
4. 报告清理目标、实际释放空间（以磁盘前后差值为准）、剩余占用、保留原因与复核日期。
5. 每次大型构建前、每周人工维护时复核预算。未另获用户授权，不创建定时删除任务。

## 清理安全边界

- `.gitignore` 只防止提交，不限制磁盘增长，也不能证明内容可丢弃；禁止 `git clean -fdx`。
- 先统计，再生成**明确路径清单**，检查源码/脚本引用、当前任务、进程及是否存在唯一成果。
  没有匹配到进程不代表没有文件句柄或其他任务引用。
- 删除前解析绝对路径，确认其严格位于预定任务子目录内；拒绝根目录、空路径、`..` 越界、
  符号链接及目录联接。对含链接的目录停止并人工检查，不沿链接递归。
- 在同一个 PowerShell 中操作，使用 `Remove-Item -LiteralPath` 等明确路径操作；
  不将枚举出的路径拼成 `cmd /c rmdir`，不用通配符删除 `backup`、环境或模型。
- 能恢复的旧成果先归档至已批准位置并验证，再删除原副本。同盘移动不释放空间；
  回收站仍可能占用原盘；永久删除不可承诺从回收站恢复。
- 不清理整个 `tmp/`、`.venv/`、`mods/`、`var/` 或系统临时目录。
