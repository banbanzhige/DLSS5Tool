# 独立预览开关与播放时钟

## 使用

「这次导出」的超分、插帧下拉框右侧各新增一个「预览」勾选项，默认关闭，分别记忆。
勾选只决定是否在播放器执行该效果，不修改下拉框倍率，不修改导出和队列快照。
图片、尚未导入视频或对应倍率关闭时，预览勾选项禁用；切换媒体不清除用户偏好。
只开插帧预览时不运行超分，只开超分预览时保持源帧率。普通 DLSS 增强预览不由这两个开关关闭。
预览和导出实际处理配置相同时继续复用缓存；配置不同不能把低倍率预览帧当作导出结果。

沿用 ui-ux-pro-max 的原位置、明确状态和可键盘操作原则，复用 CheckToggle，不增加独立面板；
新控件已登记主题更新，浅/深色、小宽度布局检查通过。

## 不同步的原因与处理

原实现没有把源时长乘以插帧倍率，但逐帧递增 UI 位置、按墙钟播放音轨，
绘制落后时还会反复从当前帧重启音轨。只有一帧可播就立即启动也容易导致频繁启停。
原时间标签使用最后一帧起始时间作为总时长，有一帧差异；这不是主要卡顿原因。

- 插帧/超分共享预览使用扫描确认的精确输出帧率和源帧数，不依赖界面估算帧率。
- 总时长为 `源帧数 / 源帧率 = 输出帧数 / 输出帧率`；2×只是输出帧数和帧率都翻倍。
  165 帧/30 fps → 330 帧/60 fps，总时长均为 5.5 秒；共享预览标签显示完整时长。
- 有可播放音轨时以 Windows 音频位置为时钟；无音轨/静音时使用单调时钟。
- 启播/真实缓存缺口先缓冲约 0.3 秒，按剩余片长和实际像素预算缩短等待窗口，
  避免小预算永远凑不满缓冲；等待期间同步暂停音频。
- UI 回调延迟时直接呈现时钟对应的已缓存帧，不拉长时间、不反复回拉音频。
  这是播放器跳过过时显示，不是少算生成帧；逐帧按钮和导出仍可消费全部生成帧。
- 修改开关先暂停、切换有效预览配置，旧会话退出后才恢复普通预取；导出过程中不撤销导出会话。

- 四种开关组合、默认关闭/设置校验、显式导出倍率不变、旧预览尺寸不放大、

  无音轨时总时长不翻倍、60000/1001 fps 精确速率以及小预算缓冲。
