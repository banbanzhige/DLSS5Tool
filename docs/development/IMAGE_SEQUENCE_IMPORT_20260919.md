# 图片序列导入（2026-09-19）

## 使用

1. 源码启动后打开右侧「队列」页，点击顶部「添加图片序列…」。
   「画面效果」页不再放置序列入口；原「导入」仍按单张图片或视频处理。
2. 选择序列中的任意一张 PNG/JPG；程序识别同目录、同前后缀、同扩展名的连续数字编号。
   例如 `frame_0001.png`～`frame_0100.png`。按数值排序，不要求从 0 或 1 开始。
3. 输入**原始帧率**（1～240，例如 `24`、`29.97`、`24000/1001`），点击「检查并加入队列」。
   整组图片作为一个视频任务加入并被选中，留在队列页，不替换当前预览素材。
4. 需要调整效果时，选中任务并使用队列的加载预览功能；调整后用「应用当前设置」更新任务，
   再启动队列导出。新任务默认保存添加时的效果/导出设置。
   导出仍使用原有整数倍率补帧；**未新增自定义目标帧率**。

队列顶部「添加文件」「添加文件夹」保留原行为，使用文字按钮便于发现。
「添加文件夹」将每个素材作为独立任务，不会自动将目录解释为序列。

支持同尺寸的 8 位三通道 RGB PNG/JPG。暂不支持灰度、透明通道、高位深、HDR/EXR、
混合扩展名、缺号、重复编号、单帧序列或外部音轨。输入不兼容时明确说明，不自动补重复图片、
丢弃透明度或降低位深。切镜与末尾保持继承现有补帧行为。
导出也继承现有共享渲染要求：最终宽高为偶数、128～8192，并受实际显卡/编码器能力限制。

输出 MP4/MKV/MOV 无音轨视频；默认文件在第一张原图旁，以 `_dlss` 命名并避开已有文件。
队列可选择其他输出目录。原图不修改、不复制、不先生成中间视频。

## 实现边界

- `image_sequence.py` 提供连续编号发现、逐张扫描、精确原始帧率、按需解码和随机定位。
- 导入扫描在后台线程执行，显示进度，可取消；保持当前素材直到新序列导入成功。
- `.dlssseq` 是小型不可变清单，记录绝对图片路径、尺寸、原始帧率及文件大小/修改时间快照。
  源码保存于 `var/image-sequences/`，发行版保存于应用旁 `image-sequences/`。
  它是队列需要的持久状态，不是临时图像缓存；不要在队列仍引用时删除。
- 在现有队列中归为 temporal/video 任务，以清单路径区分于单张图片；不同原始帧率形成不同清单，
  独立保存、独立缓存。应用重启后无需重新手动输入帧率。
- 原始预览、引导图预览/导出和共享渲染均使用同一序列读帧适配器。
- 序列导出强制走现有顺序共享渲染/编码链，不进入以视频文件为前提的分段并行路径。
- 输入帧读取前后检查文件快照；缓存导出开始、逐帧消费、完成封装前再次检查。
  图片变化后须重新导入，避免导出混用新图和旧缓存。不会后台监控源目录。
- 本功能不更改 NVIDIA SDK、模型、运行库或补帧算法；现有 3×/4×的实验限制仍然有效。
- UI/UX 技能用于独立入口、明确原始帧率说明、错误恢复提示、后台进度与取消，沿用现有主题。
