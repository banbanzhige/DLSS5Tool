# 预览效果标识 · 2026-09-19

用户反馈：视频勾选超分/插帧预览后，对比画面右上角仍只显示DLSS，容易误认为仅增强生效。

本次仅修改显示，不改推理、显存策略、缓存、导出配置或用户勾选状态：

- 根据有效预览设置显示 `DLSS · 超分 4× · 插帧 2×`，未勾选预览的导出倍率不显示。
- 勾选但倍率为1/关闭时不显示该效果；调整倍率和勾选后随原预览重绘更新。
- 分割对比、左右并排和处理结果单视图共用标识；原图和光流/深度上下文保持原语义。
- 生成中保留效果名称，仅在末尾加省略号；图像仍按现有图像超分规则显示，忽略视频插帧。
- 按用户第二版反馈，与左侧“原图”复用相同的小字号、常规字重、颜色和阴影，无底框/边框。
  左右边距均为10px，首行垂直对齐；长标签按可用宽度向下换行，中英文完整本地化。
