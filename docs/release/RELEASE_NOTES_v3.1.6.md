# v3.1.6 Release Notes

## 修复

- 修复缓存插帧、缓存增强或导出过程结束、取消及异常中断时，部分显存资源偶发清理失败导致残留占用的问题；清理遇暂时错误时会自动重试并保留诊断记录。
- 修复连续切换画面尺寸或处理参数时，共享显存缓冲尚未释放就触发重建可能引发的异常，提高多分辨率连续处理的稳定性。
- 修复增量更新失败回滚过程中，本地说明文档被占用或锁定导致回滚中断的问题。

## 升级说明

- `v3.1.5` 轻量版与完整版用户可直接使用软件内自动更新，或手动导入对应的 `v3.1.5 → v3.1.6` 增量包升级。
- 更早版本请下载 `v3.1.6` 对应形态的完整安装包升级，现有设置、队列与模型文件保持不变。

## 下载选择

- **轻量版**：主程序，不含光流推理组件和模型，适合基础增强与超分处理。推荐第一次轻量试用下载。
- **完整版（full）**：包含主程序、光流推理组件和模型；下载全部分卷后合并解压。推荐对画质和稳定性追求的用户下载。
- **推理附加包（addon）**：为同版本轻量版补齐组件和模型；下载全部分卷，合并后解压到主程序目录，完整版无需重复安装。
- **自动升级增量包（dlssupdate）**：给次版本对应升级的快速安装包，一般是软件自己拉取或者下载失败手动拉取导入的选择，新用户请下载轻量版或者full版。
