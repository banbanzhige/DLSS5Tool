# v3.0.4 Release Notes

## 新增

- 视频优先使用显卡硬件解码，新增“允许 CPU 解码兜底”开关，便于处理显卡不支持的素材。
- 导出前提示内存、显存和高分辨率任务风险，帮助判断是否需要先做短片试导。

## 优化

- 画面效果支持分组折叠，默认展开常用参数，并记住各组的展开状态。
- 区域保护单独成组，启用开关统一为勾选框；HDR 高精度开关与解码兜底开关集中排列。
- 减少超分导出中的重复画面复制，改善处理速度与内存占用。

## 修复

- 修正导出速度与剩余时间统计，按实际输出帧计算，并单独显示收尾阶段。

## 下载选择

- **轻量版**：主程序，不含光流推理组件和模型，适合基础增强与超分处理。
- **完整版（full）**：包含主程序、光流推理组件和模型；下载全部分卷后合并解压。
- **推理附加包（addon）**：为同版本轻量版补齐组件和模型；下载全部分卷，合并后解压到主程序目录，完整版无需重复安装。
