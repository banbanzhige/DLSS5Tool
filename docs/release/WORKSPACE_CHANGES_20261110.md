## DLSS 运行库自动匹配和手动测试

- 按选中的 DLSS 渲染显卡识别 RTX 30／40／50 系；40 系优先内置库，其他系列或内置库异常时复用已校验文件或下载匹配文件。
- 从本项目 GitHub `zip` Release 的固定附件下载，分别校验归档与 DLL 的 SHA-256，只提取唯一目标 DLL，拒绝链接路径及异常副本覆盖。
- 自动下载保存到组件目录的独立子目录，保留内置和用户自定义文件；旧的有效手动路径仍优先使用。
- 新增系列选择、自定义 DLL、独立进程单帧测试和结果反馈；下载及测试经后台线程与消息队列执行，关闭应用可取消下载。
- 切换渲染 GPU、运行库或组件目录会回收旧处理会话并更新缓存身份；实际宿主路径通过进程消息返回。
- 实时模式空闲启动时同步 NR 选择，并保持 SR／FG 特性目录独立；首次准备对应库后再次点击开始。
- 同步 README、使用指南、组件说明与中英文提示，新增 `scripts/check_dlss_runtime.py`。

既有实测：RTX 4070 SUPER 自动选择内置库并通过单帧处理；手动选择 50 系库报告不兼容，切回自动再次通过。
30／50 系真实附件的归档和 DLL 校验均通过，尚未在相应硬件上实测。30 系仍是社区适配。

## 非零视频起点的时间线和音频对齐

- 预检保留首个实际解码时间戳，将渲染时间线归零，同时将原视频起点传给音频封装。
- 抽出统一的时间线结束计算，优先使用精确流时基、起点与时长，并保留末帧时长兜底。
- 为普通／共享缓存导出、常驻 SDR／HDR 超分及预览 worker 传递同一源起点，消除对“必须从零开始”的错误限制。
- 恒定帧率判定只依赖相邻帧间隔；变帧率插帧仍按既有能力边界拒绝，不悄悄重定时。
- 新增非零起点 CFR／VFR、不同音轨起点，以及常驻预览／导出与实际媒体封装的关联测试。
