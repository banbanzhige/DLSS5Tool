# v2.3.1 Release Notes

## 新增

- 图片序列支持 HDR：导入 BT.2020、16 位 RGB PNG 序列时可指定 PQ 或 HLG，并进行预览、超分和插帧导出；普通 PNG/JPG 默认仍按 SDR 处理。

## 修复

- 兼容曾替换内置运行库的用户：安装本版后，后续增量若不更换该 DLL，会保留自用版本，不再仅因内容不同拒绝更新。
- 修复从模型预览页返回普通 DLSS 预览时，预缓存未恢复的问题。

## 升级说明

- v2.3.0 可使用对应的轻量版／完整版增量升级。若仍提示 `_internal/nvngx_dlssnr.dll` 被修改，先关闭程序，将适配 DLL 备份到 `mods`（已有文件不要直接覆盖），再从原版 v2.3.0 压缩包恢复内置 DLL 后重试；旧更新器不会提前获得本版修复。
- 不想重新下载完整版：原版 v2.2.2 / v2.3.0 用户可下载本版轻量包并解压到新目录，复制旧版 `mods/enhancement`、`mods/models`，再解压 `DLSS5Tool-v2.3.1-addon-component-reuse.zip` 到新程序目录。详见附件 `UPGRADE_v2.3.1.md`；不要复制旧 `_internal` 或只替换 EXE。
- 仍在 v2.2.2 的用户不支持直达本版的增量更新，请使用上述轻量包复用方案；自改过推理组件或缺文件时请选择本版完整版／附加包。

## 下载选择

- **轻量版**：主程序，不含光流推理组件和模型；已有符合上述条件的官方组件可复用。
- **完整版（full）**：主程序、推理组件及模型，适合新安装或无法复用旧组件的用户。
- **推理附加包（addon）**：为轻量版补装组件和模型；完整版与附加包需下载全部分卷后合并。`component-reuse.zip` 仅补齐复用组件的说明文件，不含程序、模型，也不是增量更新包。
