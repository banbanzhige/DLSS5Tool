## 下载选择

- **轻量版**：主程序，不含光流推理组件和模型，适合基础增强与超分处理。推荐第一次轻量试用下载。
- **完整版（full）**：包含主程序、光流推理组件和模型；下载全部分卷后合并解压。推荐对画质和稳定性追求的用户下载。
- **推理附加包（addon）**：为同版本轻量版补齐组件和模型；下载全部分卷，合并后解压到主程序目录，完整版无需重复安装。
- **自动升级增量包（dlssupdate）**：给次版本对应升级的快速安装包，一般是软件自己拉取或者下载失败手动拉取导入的选择，新用户请下载轻量版或者full版。

首次使用请核对显卡型号；需要更换运行库时，从 [显卡运行库下载页](https://github.com/banbanzhige/DLSS5Tool/releases/tag/zip) 获取对应文件，关闭程序后将 `nvngx_dlssnr.dll` 放入与主程序同级的 `mods` 文件夹。

关于压缩分包：由于上传大小限制完整版拆分成两个包.zip.001和.zip.002；需要两个包下载完成后，在同一目录下解压才能完整正常使用。
