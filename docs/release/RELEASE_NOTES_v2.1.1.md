## 增强

- 可以额外打开深度和光流，让增强不只看当前这一帧。光流看画面怎么动，视频更容易稳住、少闪；深度看远近，结构和边缘可能更清楚。不是每条素材都明显更好，深度尤其因图而异。默认关着，普通增强和以前一样。
- 推理页能直接看深度图、光流图，也能单独导出，方便确认模型有没有帮上忙。

## 使用

- 画面、模型、设置、队列分开了，找参数不用挤在一页。加了英文。
- 只改风格和强度时，不用重新等深度和光流算完。
- 光流快了一点（本机大约 174→150ms/帧）。还是 RAFT，不是硬件光流，也不会插帧。

## 修复

- 大图和超分不再一块亮一块暗。
- 超分到 8K 现在能导出。
- 切换推理不再卡住；滚页面时不会误改参数。
