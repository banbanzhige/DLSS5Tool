# v2.1.3 · HDR 光流与大图支持

## 新增

- 新增 HDR 光流支持，可配合 RAFT / NVOFA 使用，保留高精度渲染与 10-bit 导出。
- 支持 HDR 视频的光流预览和分析图导出，分析画面以 SDR 显示。
- 自定义视频输出单边上限提高至 16384，实际尺寸仍需通过编码器检查。

## 优化

- 静态图片自动跳过光流，不再因光流开启而阻止大图分块，保留视频光流设置。
- 完善超长图片与低显存显卡的自动分块策略。
- 光流分析长边增加至 2048 实验档位，默认参数保持不变。

> 完整版已包含新版推理组件；轻量版用户需配套安装 v2.1.3 推理附加包。建议解压到新目录。仍不支持静态 HDR 图片、视频时序分块及单边超过 16384 的处理。
>
> 已知限制：光流预览暂请使用不超过 1280 的分析档位；长 HDR 视频跳帧分析可能等待较久，取消需等当前读取结束；HDR＋超分建议将 GPU 队列设为 1，避免额外显存占用。
