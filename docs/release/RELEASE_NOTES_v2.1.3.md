# v2.1.3 · 原候选记录（已并入 v2.1.2）

2026-09-10 按维护者指定，本候选全部并入 [v2.1.2](RELEASE_NOTES_v2.1.2.md)，不单独发布 v2.1.3。以下保留原候选说明。

包含 v2.1.2 的深度下线改动，并新增“光流后端：RAFT / NVOFA”。
NVOFA 不使用 RAFT 权重或迭代参数，需要支持的 NVIDIA GPU/驱动。开发只从仓库根目录 `run.bat` 启动，组件位于 `mods/enhancement`。

- 初始化失败会提示并尝试 RAFT；RAFT 权重缺失则保持失败，不下载权重。
- 处理中失败会停止，不能在同一视频中途悄悄更换算法。
- 默认仍 RAFT，启动仍关闭光流。
- 本轮不裁 Torch、不分发驱动光流 DLL，不承诺稳定 30fps 或与 RAFT 逐像素一致。

尚未公开发布。
