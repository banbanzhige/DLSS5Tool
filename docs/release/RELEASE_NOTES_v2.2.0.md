# v2.2.0 Release Notes

## 新增

- 新增「DLSS 渲染 GPU」选择，支持自动选择 NVIDIA 独显或手动指定显卡。
- 新增文件级更新功能，后续升级无需重复下载未变化的组件和模型。
- 新增独立更新助手，支持校验、备份、失败回滚和中断恢复。

## 优化

- 核显输出画面时，DLSS 仍会优先运行在 NVIDIA 独显上。
- 优化多显卡识别、显卡切换和错误提示。
- 一键诊断新增实际使用的 DLSS 渲染显卡信息。
- 更新过程会保留用户设置、队列和自定义文件。

## 修复

- 修复混合显卡环境下 DLSS 可能错误使用核显，导致无法生效的问题。
- 修复显卡切换失败后影响当前预览会话的问题。

## 升级说明

- v2.1.x 用户需要手动完整安装一次 v2.2.0。
- v2.2.0 是文件级更新的首个基线，后续版本开始支持增量更新。

## 下载选择

- **轻量版**：主程序，不含光流推理组件和模型。
- **完整版（full）**：主程序＋CUDA 推理组件＋RAFT 光流模型。
- **推理附加包（addon）**：供轻量版补装，解压到主程序同级目录。

完整版及附加包采用分卷，需下载全部分卷并按说明合并。
