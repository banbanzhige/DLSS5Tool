# v3.0.1 Release Notes

## 新增

- 实时运行详情增加残差合成 GPU P95，能看出卡顿是不是卡在画面合成。

## 优化

- 本地大尺寸 SDR 画面优先使用 GPU 合成，无法使用时自动回退现有 CPU 路径，大尺寸 SDR 图片和视频的画面合成更快。
- 实时模式复用现有 native residual shader，同尺寸输入直接读取对应像素，同尺寸实时画面的合成更轻。
- 共享预览缩短预取范围，导出进度合并渲染与编码阶段，拖动和播放时预览更快跟上，导出进度不再往回跳。

## 修复

- 修复渲染 worker 失败后被后续请求继续复用的问题，失败缓存会自动重建，渲染失败后不会一直沿用坏结果。
- 修复共享预览和导出同时进行时进度显示不连续的问题，边预览边导出时进度保持连续。

## 升级说明

- 当前版本已完成源码定版；公开下载包和增量更新附件需在 v3.0.1 打包验收后提供。
