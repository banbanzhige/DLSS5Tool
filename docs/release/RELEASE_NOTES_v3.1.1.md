# v3.1.1 Release Notes

## 优化

- 改善 DLSS 初始化失败时的提示，提供更明确的处理建议。

## 修复

- 修复部分变帧率视频导出后音画不同步的问题。
- 修复音轨与画面起点不一致时，导出后产生固定偏移的问题。
- 修复视频解码提前结束时，导出仍可能显示成功的问题。

## 下载选择

- **轻量版**：主程序，不含光流推理组件和模型，适合基础增强与超分处理。
- **完整版（full）**：包含主程序、光流推理组件和模型；下载全部分卷后合并解压。
- **推理附加包（addon）**：为同版本轻量版补齐组件和模型；下载全部分卷，合并后解压到主程序目录，完整版无需重复安装。
