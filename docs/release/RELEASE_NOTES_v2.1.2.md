# v2.1.2 · 硬件光流与预览稳定性更新

日期：2026-09-10。按维护者指定，将原 v2.1.2 / v2.1.3 未发布候选统一为 v2.1.2。当前为本地打包验证，未上传发布。

## 主要更新

- 新增可选 NVOFA 硬件光流，无需模型权重；默认仅光流、RAFT-Large、512 长边、6 次迭代。首次及重启均在环境检查通过后启用；已保存的关闭模式保持关闭。NVOFA 需要兼容的 NVIDIA GPU、驱动及新版增强组件。
- 光流设置按后端显示：RAFT 迭代次数，NVOFA 输出网格（备选默认 1×1，需 Ampere 及以上；可选 2×2 / 4×4）。
- 当前调节参数设为首次默认值：光流显示量程 5、预读 120 帧、缓存 400 帧／8192 MiB、浅色主题；保留已有设置。新增预览缓存清理按钮。
- 暂时隐藏深度推理、参数、预览及导出入口：在已测运行库、宿主和素材下，深度参考未改变增强输出。保留光流；关闭光流不影响普通增强、超分和导出。
- 修复模型切换后暂停中的分析预览未刷新，复用实际预览会话，减少重复模型加载。
- 图片预览改为后台处理，保留大图分块；失败时停止等待并给出提示。推理状态改为单行，补充参数帮助和画面内进度状态。
- 细分 NGX 平台错误、版本过旧、显存不足和数据目录权限诊断；此次未确认反馈用户 RTX 4060 的具体故障根因。
- 更新中英文说明，新增用户指南与源码构建指南，修复发行说明打包路径。

## 升级说明与限制

- 旧“仅深度”按关闭执行，旧“深度＋光流”按仅光流执行；内部深度管道保留供维护者显式复开。
- 完整版／附加包仅附 RAFT-Large 权重，不再附 DAV2 权重；不自动删除用户已安装的旧文件，建议解压到新目录。
- NVOFA 初始化失败会提示并尝试 RAFT，需已有 RAFT 权重，不自动下载；运行中失败则停止，不在同一视频中途切算法，不自动回退 CPU。
- NVOFA 需要配套新版增强组件；源码提交不会替换已有便携包或其 worker。开发从仓库根目录 `run.bat` 启动。
- 本轮不裁剪 Torch、不分发驱动光流 DLL，不承诺固定帧率、与 RAFT 逐像素一致或跨硬件验证完成。
