# v2.3.2 Release Notes

## 新增

- 图片序列可以多选导入。只点一张编号图时，会补全同目录里整段连续编号；同一组选中多张时，只导入这段连续范围。同目录里其他完整序列会列出来，默认不勾选。
- 序列确认窗显示帧数、尺寸、色彩，以及按原始帧率计算的输出时长。窗口打开在主窗口中间。
- 状态栏增加 GitHub 标记。关于页显示当前版本和 GitHub 上的最新版本，仓库与作者主页可以直接打开，也可以在这里检查更新。

## 升级说明

- 本版源码已打包为本地候选，尚未上传。增量包只覆盖上一个正式版本 v2.3.1 的轻量版和完整版。
- 更早版本请使用整包，不要只替换 EXE。
