# v2.3.0 Release Notes

## 新增

- 新增图片序列导入：在「队列」添加连续编号的 PNG/JPG，设置原始帧率，超分、插帧后直接导出视频。
- 队列新增拖动多选、单项及批量右键菜单，支持 Delete、Ctrl+A、Ctrl+C 等快捷键和撤销移除。

## 优化

- 优化符合条件的 HDR 视频导出，减少画面转换和编码过程中的数据搬运。
- 拖动对比线、缩放和平移画面时保持预览与预缓存连续，修改码率等纯导出设置不再打断预览。
- 预览画面明确显示实际启用的超分、插帧倍率，长标识自动换行。
- 优化队列列宽和长文件名显示，悬停可查看完整路径，并显示已选任务数量。
- 完善一键诊断，补充超分、插帧及近期导出信息，方便排查问题。

## 修复

- 修复部分超分和混合场景下，对比画面的「原图」侧未使用真实原始画面的问题。
- 修复部分预览显示操作导致在途处理结果被丢弃、预缓存反复重启的问题。

## 下载选择

- **轻量版**：主程序，含超分、插帧及本版导出优化，不含光流推理组件和模型。
- **完整版（full）**：主程序、推理组件及 RAFT 光流模型。
- **推理附加包（addon）**：供轻量版补装，解压到主程序同级目录。

完整版及附加包需下载全部分卷并按说明合并。
