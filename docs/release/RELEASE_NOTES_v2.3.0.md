# v2.3.0 Release Notes

## 新增

- 新增 HDR（PQ/HLG）GPU 色彩转换与编码支持，增强、插帧导出可保留 HDR 色彩和 10 位输出。
- 升级 GPU 直连导出：符合条件时，增强结果和插帧画面直接在显存中交给编码器，减少 CPU 往返搬运。
- 新增图片序列导入：在「队列」添加连续编号、同尺寸的 8 位 RGB PNG/JPG，设置原始帧率，超分、插帧后导出无音轨视频；暂不支持 HDR 图片序列。
- 队列新增拖动多选、单项及批量右键菜单，支持 Delete、Ctrl+A、Ctrl+C 等快捷键和撤销移除。
- 新增导出前时间戳检查进度，长视频准备阶段可查看扫描进展，不再只有等待。

## 优化

- 优化 GPU 导出的取消与异常退出处理，及时回收编码进程，失败或取消不覆盖已有文件。
- 拖动对比线、缩放和平移画面时保持预览与预缓存连续，修改码率等纯导出设置不再打断预览。
- 预览画面明确显示实际启用的超分、插帧倍率，长标识自动换行。
- 优化队列列宽和长文件名显示，悬停可查看完整路径，并显示已选任务数量。
- 完善一键诊断，显示预览与导出的实际生效设置、HDR 和光流直连状态，辅助核对近期导出结果。

## 修复

- 修复部分超分和混合场景下，对比画面的「原图」侧未使用真实原始画面的问题。
- 修复部分预览显示操作导致在途处理结果被丢弃、预缓存反复重启的问题。
- 修复等待超分／插帧预览结果时，对比分割画面被单张原图替换的问题。

## 升级说明

- v2.2.2 可使用对应的轻量版／完整版增量包升级；更早版本请下载整包升级。

## 下载选择

- **轻量版（DLSS5Tool-v2.3.0-win64.zip）**：主程序，含超分、插帧及本版 HDR／GPU 导出升级，不含光流推理组件和模型。
- **完整版（DLSS5Tool-v2.3.0-win64-full.zip）**：主程序＋CUDA 推理组件＋RAFT 光流模型。
- **推理附加包（DLSS5Tool-v2.3.0-win64-addon.zip）**：供轻量版补装，解压到主程序同级目录。

新用户请先确认自己的显卡系列，按需到 [zip 下载页](https://github.com/banbanzhige/DLSS5Tool/releases/tag/zip) 获取匹配的 `nvngx_dlssnr.dll`；关闭程序后放入程序同级的 `mods` 文件夹，避免覆盖内置文件影响增量更新。

完整版及附加包需下载全部分卷（`.zip.001`、`.zip.002`）并按说明合并。
