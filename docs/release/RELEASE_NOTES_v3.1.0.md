# v3.1.0 Release Notes

## 新增

- 队列支持设置新任务的默认输出目录，也可批量修改未完成任务的输出目录。

## 优化

- 优化普通视频和 HDR 视频的超分处理，减少重复计算与画面搬运。
- 改善预览与导出的内存分配和缓存回收，提高处理效率。
- 优化预览等待与缓存进度提示，缓存完成后不再显示误导性的播放等待警告。

## 修复

- 修复关闭超分预览、保留导出倍率时，当前帧可能一直等待的问题。
- 修复自动预渲染提前结束的问题，内存允许时可自动继续加载到视频末尾，无需先点播放。
- 补齐补帧导出的临时空间检查，空间不足时提前提示。

## 下载选择

- **轻量版**：主程序，不含光流推理组件和模型，适合基础增强与超分处理。
- **完整版（full）**：包含主程序、光流推理组件和模型；下载全部分卷后合并解压。
- **推理附加包（addon）**：为同版本轻量版补齐组件和模型；下载全部分卷，合并后解压到主程序目录，完整版无需重复安装。
