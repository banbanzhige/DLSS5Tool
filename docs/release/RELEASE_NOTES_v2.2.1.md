# v2.2.1 Release Notes

## 新增

- 新增视频插帧，可在原有导出区域选择 2×、3×或 4×；3×/4×为实验模式，可能出现运动偏差。
- 超分、插帧各增加独立「预览」开关，默认关闭，不影响导出选择。

## 优化

- 预览与导出共享处理缓存，相同配置下已处理的画面无需重复计算。
- 调整增强参数保留超分缓存，调整输出混合可直接更新当前画面。
- 优化光流数据传输与 GPU 队列配置，减少重复处理和传输等待。

## 修复

- 修复导入视频、切换参数时预览迟迟没有反馈的问题。
- 修复插帧预览落后时反复回拉音频的问题，缓存不足时同步暂停并缓冲。

## 下载选择

- **轻量版**：主程序，含超分和插帧，不含光流推理组件和模型。
- **完整版（full）**：主程序＋CUDA 推理组件＋RAFT 光流模型。
- **推理附加包（addon）**：供轻量版补装，解压到主程序同级目录。

完整版及附加包需下载全部分卷并按说明合并。
