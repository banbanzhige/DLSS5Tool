# v2.2.2 Release Notes

## 新增

- 同一张 NVIDIA 显卡上使用 RAFT 时，光流可直接交给 DLSS，减少 CPU 搬运；兼容提交和多帧队列均可自动启用。
- 旧组件、CPU、NVOFA 等不支持直连的配置继续走原路径，不必改模型或权重。

## 优化

- 新用户默认参数与当前开发版一致：仅光流、RAFT-Large、分析长边 512、6 次迭代、光流队列 6、直连自动。
- 已有显式设置保持不变，不会写入个人路径、语言或窗口位置。

## 升级说明

- v2.2.0 和 v2.2.1 可通过文件级增量更新到本版。
- 更早版本需先手动安装带更新助手的完整包。

## 下载选择

- **轻量版**：主程序，含超分和插帧，不含光流推理组件和模型。
- **完整版（full）**：主程序＋CUDA 推理组件＋RAFT 光流模型。
- **推理附加包（addon）**：供轻量版补装，解压到主程序同级目录。

完整版及附加包需下载全部分卷并按说明合并。
