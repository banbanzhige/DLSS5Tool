# v2.3.3 Release Notes

## 优化

- 视频导入后更快开始增强预览，已显示的原图帧会直接用于处理。
- 再次导入同一个视频时，减少重复等待色彩识别；视频文件改变后会重新识别。
- 新用户默认关闭光流，以基础增强配置起步；需要光流时可在「推理模型」中开启。
- 关于页集中提供检查更新和导出诊断，诊断过程会显示进度。

## 下载选择
轻量版：主程序，不含光流推理组件和模型，适合初步试用效果的用户下载，渲染速度较快，但是可能某些情况下会出现不稳定光影情况
完整版（full）：主程序、推理组件及模型，加入了流光模型反推，适合追求更高精度的光影稳定性和连续性用户下载，渲染速度会慢些
推理附加包（addon）：为轻量版补装组件和模型；完整版=轻量版+推理附加包

新用户请先确认自己的显卡系列，按需到 [zip 下载页](https://github.com/banbanzhige/DLSS5Tool/releases/tag/zip) 获取匹配的 `nvngx_dlssnr.dll`；关闭程序后放入程序同级的 `mods` 文件夹。
