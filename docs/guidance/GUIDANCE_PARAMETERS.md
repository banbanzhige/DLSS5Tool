# 推理模型参数

顶栏：画面效果 / 推理模型 / 设置 / 队列。

「推理模型」保留分析模式、模型与两路尺寸、光流轮数、分析高级参数和图像显示。范围稳定度与百分位位于「深度高级」。设备、FP16、双 Stream 移至「设置 → 性能与设备」；组件状态和路径分别位于「设置 → 模型与组件 / 替换 DLL / 模型」。设置页另含输出与编码、预览与缓存、运行后端。导出和加入队列仍从「画面效果」底部操作，分析图导出仍在「推理模型」底部。

| 参数 | 默认 | 范围 | 作用 |
|---|---:|---|---|
| 光流分析长边 | 512 | 128–1280 px | RAFT 输入上限；模型对齐后显示实际尺寸 |
| 光流迭代次数 | 6 | 整数 1–32 | 同一对帧反复修正；直接输入或步进调整，悬浮查看说明 |
| 深度分析长边 | 512 | 128–1280 px | 独立于光流，从输入图像缩放 |
| 深度范围稳定度 | 0.9 | 0–0.99 | 归一化上下界的历史权重，不是轮廓防抖 |
| 下界/上界百分位 | P1/P99 | P0–49 / P51–100 | 相对深度归一化，非实际距离 |
| 光流显示量程 | 3 | 1–256 px/帧 | 分析画布单位；只影响可视化 |
| 深度显示 | 灰度、不反相 | 灰度/Turbo、正/反 | 只影响可视化 |

显示选项同时用于分析图预览和 PNG/MP4 分析图导出；不改变原始预测、增强视频或增强缓存键。改变分析参数会重建会话和相关缓存。旧设置的 guidance_edge 迁移为两路相同长边；新设置各自独立。所有参数保存到项目原设置流程与队列快照，导出仍使用源尺寸。

本表为 v2.1.1 应用默认值，不覆盖已有显式参数。GUI 每次启动推理关闭，启用前检查模型与环境；默认深度为 Large＋SDPA FP16，混合模式为双 Stream。RAFT 仍使用原始完整输出、6次更新和FP32，深度归一化仍为P1/P99及0.9/0.1平滑。光流输入准备优化不改变这些数值。组件在握手中回报实际参数；旧组件只允许其支持的配置，否则明确拒绝。底层旧协议的缺省值与新版应用默认值不是同一概念。见 [启用检查](GUIDANCE_ACTIVATION.md)。

验证：`python -m unittest discover -s tests -q`；Torch 环境额外执行 `tests.test_guidance_parameters tests.test_guidance_cache tests.test_guidance_execution`。
`scripts/guidance_parameters_probe.py` 对比旧/新冻结组件：3 帧合成运动上默认光流和深度逐值相同；12 轮、独立尺寸、归一化调整和双 Stream 生效，缓存重放一致。此为功能/回归检查，不代表所有实拍素材的质量结论。

运行开发版请重启 `run.bat`。增强组件位于 `mods/enhancement`；更新源码不会更新已有组件EXE。上述参数探针为早期功能验证，当前输入优化的源码／候选状态见 [首次渲染优化](../experiments/FIRST_PASS_OPTIMIZATION.md)。替换组件前关闭应用、保留备份，并确认其与主程序参数／共享缓存协议匹配，不依赖某个开发机历史备份目录。
