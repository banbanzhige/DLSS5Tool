# 可选光流参数

推理模型页选择“关闭 / 仅光流”。模式与参数都会记忆；重启时自动完成两帧检查后恢复上次启用的模式，环境缺失或检查失败才关闭。首次使用检查默认 RAFT-Large，通过后启用；已保存的关闭模式保持关闭。
当前深度参考失效，已暂时隐藏相关推理和图像选项。

| 参数 | 默认 | 范围 / 作用 |
| --- | --- | --- |
| 光流算法 | RAFT-Large | 可选 NVOFA，需支持的 NVIDIA GPU/驱动。RAFT 是神经网络模型，NVOFA 是硬件光流；切换后只显示该算法有效的处理参数 |
| 分析长边 | 512 | 128–1280；RAFT 8 对齐，NVOFA 16 对齐，实际尺寸可能略有差异 |
| RAFT 迭代 | 6 | 1–32；仅 RAFT 显示 |
| NVOFA 网格 | 1×1 | 仅 NVOFA 显示；2×2 / 1×1 需 Ampere 及以上，更密更慢。Turing 仅 4×4 |
| 方向处理 | 反向估计（推荐） | RAFT / NVOFA 均支持；直接估计当前帧→上一帧。可选前向取负（旧版兼容），两者不保证等价 |
| 光流显示量程 | 5 px/帧 | 1–256；只影响可视化，两后端都显示 |
| 设备 | 自动 / CUDA | CPU 仅供显式选择的 RAFT 调试；NVOFA 不支持 CPU |

初始化 NVOFA 失败时会提示并尝试 RAFT（必须有权重）；运行中失败停止，不中途换后端。
默认后端为 RAFT-Large。光流仍只支持 SDR、非分块。
单张图片及首帧/reset 为零光流；seek 与切镜重置历史。

“前向取负（旧版兼容）”原名“二开原方式”：先估计上一帧→当前帧，再逐位置将矢量取负，
没有将矢量重映射到当前帧坐标。因此它不等同于反向光流，运动边缘和遮挡处可能有偏差；
保留用于旧结果对照，不代表质量档位。NVOFA 的反向估计通过将当前帧作为输入、上一帧作为参考实现。
目前未接入双向一致性检查或遮挡修复，也没有据此保证某种处理在所有素材上增强效果更好。

分析图可导出 MP4 或 PNG，源尺寸、无音频，无界面叠加。显示参数不改变增强结果或推理缓存。
分析参数修改重建会话；NVOFA 不使用保存的 RAFT 迭代值，切回 RAFT 时恢复该值。

组件放置说明见包内 mods/README.md。必须保留完整组件目录；更新主程序不会自动更新 worker。
完整版/附加包仅附 RAFT 权重，不附深度权重；不自动删除旧安装文件。
