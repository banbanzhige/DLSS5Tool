# 本机实时增强

点击右上角标题栏、最小化按钮左侧的双向箭头图标，立即在「本地媒体 ↔ 实时增强」之间切换，不弹菜单。悬停可查看当前模式和点击后的目标模式。也可用 `Ctrl+Tab`，或「更多 → 工作模式」。两条流程共用一个工作台，不再打开额外的实时控制窗口；原生增强画面的输出窗口／全屏覆盖仍保留。实时增强直接处理本机正在运行的窗口，不需要采集卡或串流，也不往游戏进程注入代码。

下次打开会恢复上次的工作模式和深／浅主题，不因启动恢复再次反色，也不会自动开始捕获或增强。首次使用或旧设置未记录模式时，默认进入本地媒体。上次分离的本地预览窗口在实时模式保持隐藏，切回本地后恢复。

主动切换模式仍会反转当前深／浅主题，不把任何模式固定为某种颜色。可以随时通过「更多」手动调整主题；下次主动切换模式从你当前选择的主题继续反转，重复选择当前模式则不变色。当前模式常驻底部状态栏，切换时仅短暂高亮该标记，不移动工作区、不抢焦点，连续点击不会堆积提示。

实时界面的参数、分组、选项和提示随应用语言显示；「更多 → 语言」保存后重启生效。效果技术名称、参数 ID、预设数值和原始诊断记录不会被翻译或改写；未知第三方效果保留其原始描述。

## 同一个工作台，两种模式

- **本地媒体**：保留原来的导入、预览、时间线、调整、引导、导出和队列。
- **实时增强**：左侧是紧凑会话栏，集中选择来源窗口、来源截图、内置方案和全屏／窗口输出；个人预设与复制入口在方案下方。右侧分为「画面」「算法与流程」「输出」「高级」四页，顶部「算法库 · N」始终可达。来源截图仅用于确认窗口和定位保护区域，不是持续更新的增强效果预览。
- 日志首次默认展开，通过「更多 → 日志／收起日志」切换；下次启动记住上次的展开／收起选择。两种模式共用展开状态，但保留各自内容与滚动位置；查看旧记录时新消息不会强制滚到底部。收起日志仍会记录状态，运行错误与紧急停止提示不依赖展开日志。
- 待机时运行工具收成一行「运行工具 · 启动后可用」，输出确认就绪后自动展开「原图对比」「画面内调参」「画面内统计」「保存增强截图」。它们控制增强输出，不是来源截图；画面内统计也不同于主界面的运行详情。同一次运行中可手动收起工具，遥测更新不会反复展开。
- 待机不显示运行数据说明；运行后先显示一行性能摘要，有当前会话数据后才提供可展开的运行详情。指标帮助仍明确：处理速率不等于游戏 FPS，显卡负载包含其他进程。实时日志默认紧凑显示四行，仍记住开关状态并持续记录，错误／警告分色。快捷键不可用时可直接点「设置快捷键…」查看状态或修改；停止快捷键不可用始终单独提示，不因收起日志而隐藏。实时模式隐藏本地待机信息，后台本地导出／队列仍保留状态。
- 左侧设置可以滚动；开始／停止、实际会话、关键通知及紧急停止提示固定在底部，展开预设不会挤走操作入口。运行中不再常驻一个可点击的重启按钮，参数需要重启时在右侧底部确认。选择其他窗口只改变待编辑来源，正在运行的窗口仍单独显示；点击「切换并重启」才切换，新来源草稿不会提前应用到原窗口。
- 内容超出可见区域时才显示滚动条，能完整显示时自动隐藏并回到顶部。拖动中间分界时显示位置预览线，松开后一次性调整左右宽度，避免持续重排造成卡顿；Esc 可取消，双击恢复默认。聚焦分界后可用左右方向键微调、Home 复位。本次打开期间切换模式或调整窗口大小会保留已确认的手动宽度，空间不足时暂时限制宽度，避免挤掉两侧控件。
- 切换不会清空素材、播放位置、队列、实时目标或未应用的参数。本地播放切走时暂停，切回不自动播放；导出任务继续。原来手动分离的本地预览窗口在实时模式暂时隐藏，切回恢复。
- 实时增强不会因为切换而启动或停止；会话存在时，底部状态栏显示实际会话状态和「停止增强」，包括初始化、恢复和源窗口最小化后的等待状态。未运行时隐藏这一组控件；选择另一个待编辑目标不会改变状态栏中的正在运行目标。
- 本地与实时参数独立；实时预设不会修改已经排队的本地导出任务。统一入口不意味着两条渲染管线或画质参数已经合并。

## 开始使用

分隔线平时为细灰线，悬停、拖动或键盘聚焦时高亮；拖动热区、默认栏宽和手动宽度记忆不变。

左侧先选来源、内置方案和输出方式；右侧「画面」直接展示当前效果的常用参数。第 2／3 遍增强紧接常用参数；「精细调整」是静态标题，内部各组只折叠一层，不再套「更多画面参数」。专家参数、第三方原生分组及所有数值完整保留；展开状态在本次工作台中记忆。宽高按步骤缩放方式显示倍率或像素单位。

常用参数与本地媒体统一为「风格」「强度」「本地色调」「本地结构」「皮肤蒙版」。皮肤蒙版使用同一行的开关、数值框和滑条：关闭后滑条灰显并保留数值，实际按关闭处理；开启后恢复记忆数值，数值为 0 时仍等同关闭。第 2／3 遍采用相同操作，撤销同时处理开关与数值。旧预设仍使用原来的两个参数字段，载入后按这一联动规则生效。

「强度」「本地色调」「本地结构」也采用同一行的开关与数值，关闭按 0 处理并记忆数值；第 2／3 遍相同。开关状态随参数预设保存，旧预设没有这些开关时按开启读取，不改原有数值。输入框支持小数和百分比，保留有效精细数值；超范围或无效输入会就地提示，不自动截断。参数范围、默认值及能否实时生效仍以各自后端为准，不强行改成本地范围。

常用强度数值正常显示为 `1.00`、`0.75`，不再因后端浮点步长尾差补出多余小数。「扩展调节范围」作用于三遍的强度、本地色调、本地结构、皮肤蒙版：默认 0～1.00，开启后最高为后端范围（当前 2.00），不是本地的 5.00。旧预设含高值时自动开启并保留，包括未启用遍数或关闭参数的记忆值。关闭时若任一相关值超过 1.00 或输入无效，会提示先修正，不自动截断。范围开关本身不提交参数或重启增强，随预设／确认后的会话记录保存；复制依然遵守目标当前选择的范围。

滑条标出 0、1.00 和上限，1.00 是常规强度参考而非画质百分比。实时步进继续遵守后端的 0.05，本地为 0.01；输入框保留精细草稿不代表原生运行值支持同等精度，画面内面板与原生热更新仍按后端步长处理。本轮不修改 shader、原生步长或运行上限。

「从本地媒体复制画面参数…」只覆盖唯一 NR 步骤第 1 遍的上述五项，先展示覆盖清单并确认；保留后续遍数、其他效果、保护、捕获和显示设置。复制后仅更新草稿，可撤销，不会自动启动、重启或提交到正在运行的会话。本地也提供反向复制入口，两边仍独立保存；超出目标范围时整次拒绝。操作详见[本地画面参数](USER_GUIDE.md#画面参数)。

悬停参数可查看作用说明。「强度」控制当前这一遍 NR，「残差倍数」放大 NR 对原画面的改变量，「画面 → 残差合成」的「最终合成强度」则控制残差合成阶段的整体变化，三者不是同一参数。「画面内 UI 修正（实验性）」向 NR 引擎传递修正开关，不是调整本软件的界面排版；当前未验证其对 HUD／字幕的保护效果，可能没有可见变化。需要保留固定位置的文字、血条等，请使用保护区域，不能把此开关当作自动识别保护。

「扩展调节范围」位于「画面调整」的参数下方，与本地模式的操作顺序一致；范围、记忆值及关闭前的检查保持不变。

「画面调整」首次默认展开，手动收起后仍记住选择。不再显示“非默认”计数或逐项默认值提示；
「待应用」仍由引擎确认状态单独表示。第 2／3 遍通过标题旁的「启用」开关控制，
不再重复显示「未选用」。撤销入口分别标为「撤销方案」「撤销调参」，不与刷新来源混淆。

### 先选方案，再调步骤

- **细节增强**：NR 单遍，保持输入尺寸。
- **放大增强**：NR 单遍 + Lanczos 1.5 倍；可在对应步骤里改倍率，或更换缩放算法。
- **动漫／线稿**：Anime4K Restore S，保持输入尺寸，不自动叠加 NR。
- **自定义**：保留当前内容，打开完整算法库。

选择方案会先显示实际步骤预览，点击「载入草稿」才替换画质步骤并重置其参数。保留已有插帧、捕获、显示和保护设置，不直接修改正在运行的会话；仍需开始增强或确认应用。缺少所需算法时该方案不可载入，不偷偷换成其他算法。最近一次载入、添加、移除、排序或更换，可通过「撤销步骤修改」恢复；与单项参数撤销分开。

「输出 → 流畅度」集中放插帧、同步和目标帧率。插帧独立选择关闭或一种算法，只更新草稿；重新选择当前算法保留参数与原有位置，关闭插帧不移除限帧效果。目标帧率不是实测帧率；性能策略只改调度与优先级，不改画质或处理分辨率。这里提供算法入口，不代表本机已验证兼容。

效果链以步骤卡片显示用途、实际算法和缩放设置。点击卡片后可「调参数」「更换算法」「移除」，通过上移／下移调整顺序；键盘方向键也能选择步骤，回车定位参数。最后一个步骤不能移除。卡片与上方方案预览都表示编辑草稿，实际生效仍看下方运行摘要。

### 完整算法库与处理流程

点击顶部「算法库 · N」直接进入「算法与流程」中的完整目录，不必先展开其他设置。页面保留当前步骤卡片和独立的「按用途选择算法」单层分组，可按增强、尺寸、锐化、抗锯齿等用途选算法。同一已知算法的模型／质量变体在二级选择中；已有步骤也可在画面参数区切换变体。更换会重置该步参数、保留缩放设置，并支持撤销；不同操作及未知第三方算法不会强行合并。

「算法库 · 全部效果」不折叠，保留分类、搜索及收藏，支持一键「重置筛选」。顶部数量按实际加载目录计算，包含模型变体，不保证每项在本机都能运行。本构建未提供的效果仍可查看说明，但标为不可用、不能添加。搜索可用原始名称、分类或用途；收藏仅保存在本机，不随画质预设导出。重复插帧被阻止，重复效果／同用途叠加给出提醒，不自动删除现有步骤。

库中默认「添加」新步骤；要替换，先点击步骤卡片「更换算法」。此时库中会显示正在更换第几步、参数重置说明与「取消更换」。切换页面、打开算法库、搜索及重置筛选不会丢掉未完成的参数输入，也不启动或重启增强。

效果、残差合成、输出和预设等说明只保留短提示。悬停现有标题、提示文字或区域示意图可查看完整说明，不再设置 ⓘ 或点击展开的重复正文；用 Tab 聚焦帮助文字或分组标题同样可查看，Esc 隐藏提示。方案与参数的撤销改为回退箭头图标，悬停可区分作用范围；撤销不等于恢复默认值。

输入分辨率比例、光流质量、第 2／3 遍参数会随对应开关和选项启用；暂不可用的控件灰显并说明原因，不删除原有值。「待应用」表示尚未由当前运行引擎确认。悬停常用画面参数的滑条或数值框可查看作用和当前可调范围。

第 2／3 遍在分组标题右侧单独勾选，默认仅运行第 1 遍。展开分组只是查看参数，不会启用增强；「已选用／未选用」表示当前编辑选择，实际运行中是否生效仍看下方应用状态。第 3 遍必须先启用第 2 遍；关闭第 2 遍会同时关闭第 3 遍，但保留两遍的参数。原有预设明确选择了多遍时会保留，不自动覆盖；运行中需重启的改动仍须手动确认。

实时参数区不再设置逐项或分组复位按钮。仅在「画面」当前效果标题旁的「···」菜单保留「恢复当前效果默认参数…」，确认后恢复该效果的参数和开关，不修改其他效果、步骤输出尺寸、设备、保护区域或已保存预设，也不重置整个应用。「撤销调参」可回退最近一次编辑或恢复操作；切换效果或载入预设后重新记录。恢复与撤销遵守相同的实时应用／确认重启规则，升级不会主动重置之前的设置。

运行中，支持实时调整的参数在松开滑条、确认数值或选择选项后提交；底部显示应用状态，等待引擎确认后才标记已应用。需要重启的修改由你点击「应用并重启」确认，不会在拖动时反复重启。尚未运行时只保留编辑草稿，点击左侧「开始增强」应用。

应用区显示待处理数量或需要重启的原因（效果链、输出缩放、参数、捕获／显示设置）。提交失败或确认超时会保留草稿，提供「重试应用」；输入无效时先修正输入。这里的编辑状态不替代底部状态栏的实际运行状态。

编辑配置与实际运行有差异时，可在「算法与流程」的差异说明中查看两种状态，按处理顺序展示，例如「NR 单遍 → DLSS SR → CAS」。正常情况下不重复常驻两份摘要。

- 上行表示编辑配置：未启动时为「待启动」，运行中有修改时为「待应用」，无效输入为「草稿待修正」。更改多遍开关会立即反映在这里，但不代表已经生效。
- 下行只显示经引擎确认已输出画面的「实际运行」效果链。启动、重启或恢复期间显示尚未确认新输出；等待源窗口时显示「上次确认」，停止后不再显示正在运行。发送启动请求不算确认。

1. 先运行游戏或应用，采用窗口化／无边框模式。在「实时增强」中刷新并手动选择目标；刷新不会自动改选其他窗口。
2. 在左侧选择「全屏输出」或「窗口输出」，两者都只增强所选窗口，不是整个桌面。默认效果链是 NR 增强。点击「开始增强」，等待实际画面确认；初始化完成不等于已收到画面。
3. 使用 `Ctrl+Alt+F10` 退出增强。画面内退出提示保留在左下角，与顶部工具栏同步显示：首次实际输出后展示 5 秒，再一起淡出；普通鼠标悬停顶部、固定工具栏或调参时重新显示。主界面仍保留退出说明。画面内提示不接收点击、不抢焦点；紧急停止键不可用时则保持警告可见。退出处理独立于实时宿主；请求停止后约 2 秒仍无响应，会只结束本次实时宿主并尝试恢复鼠标。快捷键被占用会明确提示，全屏启动不会在缺少紧急停止键时继续。
4. 遇到问题先按停止。原游戏／窗口不会被替换或关闭；切换配置失败时会尝试一次恢复最近成功的配置，但紧急停止或宿主异常退出后不会自动重启全屏。如系统本身无响应，可用 `Ctrl+Alt+Delete` 打开任务管理器，结束 `dlss5_realtime_host.exe`。

WGC 是默认捕获方式。GDI、DWM 和 Desktop Duplication 可用于兼容性尝试；DD 无首帧时默认尝试 WGC，界面明确显示实际切换，设置中可关闭。受保护画面、独占全屏、反作弊或高权限目标不能保证兼容。

### 全屏与窗口输出

窗口／全屏切换常驻左侧，只有一个可编辑入口；点击「输出方式」标题旁的「设置 ›」进入右侧「输出」，调整显示器、倍率、同步和帧率。常规输出说明移到悬停帮助，自动纠正不兼容选项时仍显示原因。输出页的「当前草稿」摘要不表示实际运行已经改变。捕获方式、设备和兼容性设置仍在「高级」。新会话默认窗口输出；旧会话／预设保留原选择。

优先按名称选择显示器和 GPU；原始显示器 ID 与 GPU 序号保留在「高级 → 图形设备 → 专家：设备编号」。已保存设备没有列出时会明确提示，不擅自改成自动或其他设备。输入处理分辨率、各算法的「步骤输出尺寸」、最终「窗口输出倍率」分属不同阶段，不会合并数值。

- 选择窗口输出时，若原来使用 DD 捕获，会改为 WGC；若开启全屏游戏鼠标模式，会关闭并灰显该项。发生联动时就地说明，其他兼容捕获方式不变。窗口模式下再选择 DD 也会回到 WGC，不会偷偷切成全屏。
- 「输出」页的窗口倍率支持 1～4，仅窗口输出时可调；全屏时灰显并保留数值。切回全屏不会自动重新开启 DD 或游戏鼠标模式。
- 运行中更改输出方式只修改草稿，需点击应用并确认重启才生效，不会立即中断当前画面。
- 当前一次只能增强一个目标；多显示器范围不是同时增强多个窗口。

### 启停提示与游戏鼠标

以下按键为初始设置；修改后以界面和增强画面显示的实际按键为准。

启动时，在目标／输出窗口中央显示「正在启用 DLSS 增强…」；真正输出首帧后短暂显示「DLSS 增强已开启」。不含 DLSS 的效果链使用「实时增强」文案。停止时显示「正在退出增强…」，确认停止后短暂显示「已退出增强」，不会为了显示提示拖延退出。切到其他应用时不在其上方显示中心提示；异常退出不冒充正常完成。

鼠标隐藏或锁定时，可按 `Ctrl+Alt+P` 打开画面内参数面板，进入可使用鼠标的编辑状态；再按一次关闭并交还游戏控制。全屏游戏鼠标模式下，启动提示仍展示 5 秒，但游戏中的相对鼠标运动不会自动唤起工具栏，需主动进入调参。此时会切换输入焦点，并非同时操作游戏和参数。

在编辑状态按 `Esc` 或点击面板外，先退回只读预览；这次返回点击会被接收，不作为游戏点击。再次按 `Ctrl+Alt+P` 可关闭面板。全屏游戏鼠标模式下，只读预览不接收鼠标，避免隐藏光标碰到面板后意外解除锁定；关闭后再按快捷键可重新编辑。仅当前台属于本次增强窗口时才尝试切入编辑，切到其他应用不会强抢焦点。快捷键被占用时会提示回主界面操作；无法取得焦点、游戏自行重新锁鼠标或目标权限不兼容时，先用 `Ctrl+Alt+F10` 停止，再在主界面调参。

以上保护不等于所有游戏均兼容。优先使用窗口化／无边框游戏；独占全屏、反作弊及高权限窗口仍须逐个验证，不注入游戏，也不绕过其保护。

## 启动检查

手动「启动检查」位于「高级 → 运行库与诊断」，只检查配置，不开始增强；点击「开始增强」或确认重启时会自动检查。检查问题直接显示在左侧会话栏，仍可定位并修正，不另开控制窗口。未选择来源窗口时开始按钮不可用。

- **需处理**：如目标已关闭、引擎或当前 NR 文件缺失、效果不可用、重复插帧、HDR 捕获方式不符，或已确认全屏紧急停止键被占用。修正后才能启动；检查阻止新请求时不会停止已有会话或清空待应用参数。
- **提醒**：如窗口最小化、引擎／效果目录尚未就绪、NR 路径回退，或指定目录未找到 SR／FG 文件。可以先处理，也可以点击「仍然启动」；此时会重新检查，不能绕过新出现的阻碍。
- 在问题列表中选择一项，点击「定位设置」跳到对应目标选择或参数页。NR 路径问题会切换到同一个工作台里的本地 NR 模块设置；修改后需要重启应用。安装问题可直接导出诊断，不自动下载或修复文件。
- 全屏紧急停止键不可用时，可到「高级 → 实时快捷键」更换组合并检查保存；也可关闭占用程序后重新检查，或改用窗口输出。改变配置、目标或引擎状态后，旧检查结果会标记过期。

检查只读取窗口身份、文件是否存在和当前引擎已报告的信息，不加载 DLL、不启动 GPU 探针、不恢复或捕获目标窗口，也不自动改设置。SR／FG 还可能由引擎从其他位置加载，因此指定目录缺文件只是提醒。检查通过不等于显卡、驱动、游戏兼容性或画质已验证；实际启动仍以原生引擎结果为准。

## 自定义实时快捷键

「高级 → 实时快捷键 → 设置快捷键…」集中管理退出增强、原图对比、画面内统计和画面内调参。快捷键异常提示也可直接打开此窗口。

- 输入组合键，例如 `Ctrl+Shift+F10`，点击「检查并保存」。支持 Ctrl / Alt（可加 Shift）搭配字母、数字或 F1～F24；至少包含 Ctrl 或 Alt，不支持 F12、Win 键和 Alt+F4。
- 只允许停止增强后改键。注册成功后立即生效，下次启动记住；不需要重启整个应用，也不清空画面草稿或撤销记录。普通快捷键不能重复，紧急停止键不能留空。
- 被占用或注册失败时不保存新设置，尝试重新启用原按键；恢复失败会明确提示，以右侧实际可用状态为准。紧急停止不可用仍禁止全屏启动，可使用停止按钮。
- 修改只保存在本机，不随效果预设导入导出，也不影响本地媒体快捷键。原生工具栏和退出提示同步显示实际组合。旧引擎不支持自定义时会提示更新，不会把未生效的按键显示为已生效。

## 效果与画质

选项多，是因为保留了多套算法及其模型、倍率、质量变体，不代表有这么多种 DLSS，也不需要全部加入。筛选只改变候选列表，不会修改现有效果链；效果从上到下依次处理。

| 用途 | 常见名称 | 作用与注意事项 |
| --- | --- | --- |
| 同分辨率增强 | DLSS NR | 默认链，用于增强细节和结构；先单独调好它。 |
| 放大／缩小 | DLSS SR、FSR、NIS、RAVU、NNEDI3、Bicubic、Lanczos | 尺寸变换，算法与开销不同；SSimDownscaler 专用于缩小。捕获式 DLSS SR 不等同于游戏内 DLSS。 |
| 动漫／像素画 | Anime4K、CuNNy、ACNet；xBRZ、Nearest | 面向线稿、动画或像素边缘，写实画面应单独对比。 |
| 锐化／抗锯齿 | CAS、RCAS、Sharpen；FXAA、SMAA | 锐化强化边缘，抗锯齿平滑边缘；过度叠加可能带来光晕或变糊。 |
| 色彩／风格 | Color、Deband、ImageAdjustment；CRT | 调色、去色带或模拟复古显示器，不是必选的增强步骤。 |
| 帧处理／诊断 | DLSS FG、FrameRate_Filter；Diagnostics | FG 生成中间帧；FrameRate_Filter 是节拍／限帧控制，不是插帧；诊断效果用于排查。 |

先用默认 NR 链；需要改尺寸时增加一种合适的缩放算法，需要更流畅时再单独评估 FG。候选列表表示当前构建提供了入口，不代表显卡、运行库和目标窗口已通过兼容性验证；当前未编译的后端仍不显示为可用选择。

- 效果链可排序、组合 NR／DLSS 超分／DLSS 插帧／颜色及缩放 shader。高级目录可查看未提供后端的说明，但不能把它们加入新步骤，不用空效果冒充支持。
- NR 保留上游完整参数，包括多遍增强、输入分辨率、光流质量和时域稳定。稳定功能默认关闭，可按场景启用。
- 「残差合成」控制总强度、暗部、亮部、颜色和亮度，处理的是 NR 对原画面的改变量；总强度为零时回到基底。
- 未运行时，手动选择来源会自动截取一帧，也可点击截图下方的刷新图标；旁边的选区图标用于设置保护区域。悬停或键盘聚焦图标可查看动作说明。预览区始终显示边框，未选来源时提示「选择窗口，预览来源画面」。「刷新窗口」只刷新列表，不额外截图。截图只保存在内存，标明原始尺寸和时间。启动增强后取消截图任务并保留静态图，不继续取帧；停止后可手动刷新。最小化、黑屏、不支持截图或超时都有提示，不会因截图失败就阻止增强，也不会自动恢复窗口、切换焦点或改为截取整个桌面。
- 点击截图下方保护区域图标或双击截图，在放大画面内拖动新增最多四区；拖动区域移动、拖动角点缩放，支持删除选区。Tab 选区、方向键微调、Delete 删除，点击「应用保护区」才写入草稿；取消不改参数。黑边不参与坐标换算，窗口尺寸或布局变化后应刷新并确认位置。截图旁显示已设区域数量；「画面」保留保护开关、羽化和原始坐标快捷入口，坐标编辑放在「高级」，使用同一份数据。运行中停止增强后可重新框选；保护区不会自动识别或跟踪 HUD／字幕。
- 可实时修改的参数由运行后端确认；需要重建的修改请使用「应用配置并重启增强」。实时修改会等待实际生效确认，不把请求已发送当作已应用。
- 原图／增强对比、参数面板、性能统计和增强截图均可从界面按钮打开。前三项初始快捷键分别为 `Ctrl+Alt+C`、`Ctrl+Alt+P`、`Ctrl+Alt+F`；可在「高级 → 实时快捷键」修改。系统占用时仍可使用按钮。

NR 运行库与主应用共用选项。「高级」页显示其来源，悬停可看选择路径；停止实时增强后，在本地「设置 → 替换 DLL / 模型」更改 NR 选择，下次开始时同步。需要首次下载对应库时会在后台准备，完成后再次点击开始。

默认按显卡识别 RTX 30／40／50 系并匹配 NR 库；30／50 系缺少文件时从项目 GitHub 下载并校验，40 系使用内置库。手动选择优先，可指定系列、内置库或自己的 DLL，再用「测试所选 DLL」进行独立进程单帧测试。自动下载保存在 `mods/dlss/` 下，不覆盖现有 DLL；30 系使用社区适配库。未识别显卡仍沿用本地文件发现规则。

SR/FG 缺少运行库时，在「高级」页选择自己已有且可信的目录；这个目录与 NR 文件选择不同。目录仅保存在本机，不随外部预设导入。

## 预设与性能

完整预设可命名并绑定应用。NR-only 预设只改 NR 参数和残差合成，不改 SR/FG、尺寸、设备和捕获。JSON 导入不会注入程序／DLL 路径，显示器和 GPU 选择仍使用本机设置。

「我的预设」通过「完整配置 / 仅 NR 画质」切换类型，两类共享「载入 / 保存… / 更多」操作，各自保留选中的预设。载入仅更新草稿，不会启动或重启增强。完整配置下可勾选保存时绑定应用；NR 画质不绑定应用。「更多」中导入会自动识别文件类型，导出采用当前类型，无需再勾选“只导出 NR”。「从本地复制…」仍保留原来的覆盖确认与撤销规则。窄窗口下操作按钮自动移到选择框下一行。

选中已绑定预设的来源应用时，在预设折叠区外显示绑定的预设名称，便于确认自动载入的来源；它不表示当前草稿没有后续修改。

均衡、游戏优先、节能、跟随显示器是显式调度档位，不会偷偷降低画质或更改 NR 分辨率。目标节拍是处理输入的限制，不是保证的游戏帧率。

统计分别显示新捕获、NR 调用、真实帧、生成帧、提交次数、NR GPU 时间和取帧到提交的 P95。静止画面可能不产生新捕获；重复提交不计作新真实帧。上述时延不是输入到光子延迟。整卡显存／功耗包含游戏和其他进程，不等于增强模块独占开销。

## HDR 与兼容边界

HDR 需要源显示器和所选输出显示器已在系统中启用 HDR，且使用 WGC。程序不会替你修改 Windows 显示设置。没有 HDR 环境会明确拒绝，不会静默改成 SDR。

多显示器、指定 GPU、DPI 感知、游戏相对鼠标、非置顶输出入口均已接入，但实际兼容范围以[验收记录](development/REALTIME_IMPLEMENTATION_20261003.md)为准。当前本机为单个 SDR 桌面，真实 HDR、多物理 GPU、混合 DPI 与 OBS 并发尚未完成实机验收。

窗口链路不能获得游戏原生深度、运动矢量或独立 UI 图层；NR/SR/FG 基于已渲染画面处理，不等于提高游戏引擎本身的 FPS。

## 导出诊断

底部日志与本地模式一样使用简短的自然语言记录，如「[实时] 已发现 1 台显示器…」「[实时] 正在初始化」。不再直接输出协议 JSON、成功回执或高频性能数据；常见错误给出原因与操作提示，并保留诊断编号。未知引擎消息保留原文。原始事件、参数、设备路径及性能数据仍按诊断保留上限收集，不因界面简化而删除。

- 两种模式共用「更多 → 导出诊断日志…」，「关于 → 导出诊断」也走相同入口。不必切回实时模式，报告会包含已经打开的实时工作台状态。
- 默认是轻量快照，在后台保存 `.log`／`.txt` 或结构化 `.json`，不启动 GPU 探针。包含本地设置与日志、实时运行配置、尚未应用的原始草稿、错误与生命周期记录、最新性能数据，以及限量读取的原生日志尾部。输入尚未填完也可以导出，不会为导出而应用参数或重启会话。
- 错误与生命周期记录独立限量保留，不会被高频性能数据挤掉；超出保留上限会记录省略数量。原生日志最多读取当前及三份轮转文件，各 256 KiB；这不是完整历史归档。
- 需要进一步排查本地渲染后端时，选择「更多 → 深度检测并导出…」。会先询问确认，并要求停止实时增强、本地导出／队列及后端切换，避免额外探针争抢资源。深度检测复用原有本地后端、超分和插帧探针，不代表目标游戏的实时捕获兼容性已经通过。
- 报告会隐藏目录路径及已知目标窗口标题，保留文件名、参数和错误码；不包含画面，不自动上传。自定义文本仍需在分享前检查。写入失败不会覆盖已有报告。
